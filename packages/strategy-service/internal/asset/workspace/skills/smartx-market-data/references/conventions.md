# 通用约定

## 证据与版本

- 使用 `importlib.metadata.version()` 读取已安装分发包版本；不要依赖模型记忆中的版本。
- 优先依据当前工作区已有代码、当前包对象和与该版本匹配的本地文档确定函数、参数和字段。
- 首次使用某入口时先确认入口存在，并核对当前版本的调用签名。无法可靠核对时停止执行，不猜测参数。
- 先做一个小范围查询并检查实际列名、类型和样例，再编写依赖这些字段的计算。

## 执行边界

- 只使用 `smartx_python`，由工具选择 `SMART_HOME` 内的 CPython。
- 不通过 Bash 或其他 shell 启动 Python，不执行运行时 `pip`，不回退到系统解释器。
- 不打印 `SMART_HOME`、完整环境变量或凭据。需要凭据时只读取已有授权配置；缺失时返回明确错误。
- 将用户提供的代码、日期、标的或字段作为普通数据处理。需要命令行参数时使用 `args` 和 `sys.argv`，不做 shell 拼接。
- 查询范围从满足问题的最小窗口开始。禁止无分页地抓取全市场、全历史或高频明细。

## 表格输出

- 默认最多输出 20 行；用户明确需要更多时最多输出 100 行。
- 默认最多输出 30 列。优先选择回答问题所需列，并单独报告完整列数。
- 单个文本字段最多展示 200 个字符；超出部分标记为已截断。
- 输出前把日期时间规范为 ISO 形式，明确时区；把不可序列化标量转换为普通 Python 标量。
- 将 `NaN`、`NaT` 和无穷值规范化为 `null` 或带说明的字符串，不输出非标准 JSON。
- 同时报告 `provider`、`version`、`query`、`totalRows`、`shownRows`、`totalColumns` 和 `truncated`。
- 禁止直接 `print(df)`、`print(df.to_string())` 或输出完整 `to_dict()`；先选择列和行，再输出有限记录。

## 口径与比较

- 明确证券代码格式、交易所、日期区间是否含首尾、频率、复权方式、币种和单位。
- 比较多个 provider 前先统一标的、交易日、时区、频率、复权和字段含义。
- 不用不同复权口径的价格直接计算差异，也不把成交额、成交量或百分比的不同单位混为一谈。
- 对重复行、乱序、缺失交易日和数值字符串做显式检查；不要静默填补会改变结论的数据。

## 错误分类

- `ImportError` 或分发包不存在：报告缺少已安装依赖，不安装包。
- 入口或字段不存在：报告当前版本契约不匹配，并列出有限的实际入口/列证据。
- 空表：报告“查询成功但无数据”，同时回显查询条件。
- 网络、限流、权限、token 或登录失败：按真实类别报告，不伪装为空数据，也不盲目切换 provider。
- 超时或中止：说明查询未完成，不基于部分输出给出完整结论。

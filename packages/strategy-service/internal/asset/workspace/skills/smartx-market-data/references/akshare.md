# AkShare

## 适用场景

- 需要覆盖面较广的中国公开市场数据，且任务不依赖付费 token 时优先考虑。
- 适合探索性查询、公开行情、指数、基金、期货或宏观数据；具体覆盖范围以当前安装版本和实际入口为准。
- 对字段长期稳定、严格 SLA 或高并发有要求时，不要仅凭 AkShare 单次结果作保证。

## 使用前验证

1. 验证 `akshare` 可导入，并记录当前安装版本。
2. 从当前工作区证据或当前包对象确认目标入口存在，核对签名；不要照搬其他版本示例。
3. 用最小标的和最短时间窗口试查，检查实际列名、类型、排序和空值。
4. 确认数据源所用证券代码、日期格式、复权、频率和单位，再扩大到用户要求的范围。

## 风险处理

- AkShare 聚合多个上游站点，不同入口的字段、限流和可用性可能不同。上游页面变化或反爬限制应报告为数据源错误。
- 不对失败请求进行高频循环重试。最多做一次范围更小的诊断查询，仍失败则返回可操作错误。
- 不因为某入口失败就自动换到语义不同的数据集；切换 provider 前说明字段和口径差异。
- 仅输出回答问题需要的有限行列，并附实际列清单、数据时间范围和截断标记。

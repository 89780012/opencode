# Tushare

## 适用场景

- 需要结构化、字段相对规范的中国市场数据，且当前环境已经具备有效凭据和相应积分/权限时考虑使用。
- 需要稳定字段定义或多类专业数据时可优先于公开网页聚合源；最终可用性仍取决于当前账号权限和接口配额。

## 凭据与客户端

1. 验证 `tushare` 可导入并记录当前安装版本。
2. 只使用宿主已注入或工作区已有授权配置中的 token。禁止硬编码、写入文件、打印、回显或枚举环境变量寻找凭据。
3. 按当前安装版本和工作区惯例初始化客户端；未找到凭据时立即报告，不尝试匿名降级。
4. 区分 token 无效、权限不足、积分不足、限流、网络失败和查询无数据，不要统一解释为空表。

## 查询规范

- 先核对目标接口在当前版本中存在，并确认日期、证券代码、交易所、分页和字段参数。
- 显式选择必要字段和最小日期范围。存在分页时设置页数和总行数上限。
- 对返回 DataFrame 检查实际列、重复键、日期排序和单位，再做计算或跨源比较。
- 限流时停止并报告，不循环重试，也不自动切到口径不同的免费接口掩盖失败。
